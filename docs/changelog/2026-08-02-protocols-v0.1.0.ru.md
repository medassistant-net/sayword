# Протоколы — v0.1.0

**2026-08-02**

Первая распространяемая сборка приложения **«Протоколы»** — программы для macOS, в которой
врач-рентгенолог просматривает и одобряет протоколы КТ/МРТ, автоматически разбитые ИИ по
категориям, перед тем как они попадут в эталонную базу для дальнейшего формирования
заключений ИИ.

- **Подписанное и заверенное Apple (notarized), самодостаточное приложение.** Не нужен ни
  Docker, ни что-либо ещё — укажите папку со своими DOCX-протоколами, и вся обработка идёт на
  вашем компьютере, а настройка и просмотр — через встроенный интерфейс в браузере. В интернет
  уходят только обезличенные тексты, для категоризации и оценки качества ИИ.
- **Удаление персональных данных — локально, до отправки чего-либо.** ФИО, даты рождения и
  похожие данные убираются из текста протокола прежде, чем он попадёт в категорию или получит
  оценку. Всё, в чём модуль удаления не до конца уверен, попадает в отдельную очередь проверки
  — протокол нельзя оценить или экспортировать, пока человек не подтвердит его вручную.
- **Категоризация и оценка качества с помощью ИИ.** Протоколы автоматически группируются по
  типам патологий и получают оценку 1–5 за полноту и ясность — это позволяет врачу
  сосредоточиться на лучших протоколах в каждой категории, а не читать всё подряд.
- **Редактируемые категории, очередь проверки, работа с клавиатуры** (одобрить/отклонить/
  пропустить, назначить категорию, поиск по всей базе).
- **Устойчивость к сбоям сети.** Обрыв соединения во время (пакетной) оценки качества теперь
  автоматически повторяется; а если сбой всё же произошёл, следующий запуск подхватывает уже
  отправленный пакет вместо того, чтобы отправлять и оплачивать его заново.

Сборка для macOS подписана и заверена Apple (Apple Silicon), проверена через
`spctl`/`stapler`.
