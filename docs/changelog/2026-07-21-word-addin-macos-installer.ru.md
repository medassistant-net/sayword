# Надстройка для Word — v1.1.1: установщик для macOS в один клик

**2026-07-21**

Установка на Mac больше не требует диалога «Переход к папке» в Finder и ручного
копирования файла. Теперь всё делает подписанный и заверенный Apple (notarized)
установщик `.pkg`.

- Скачать, дважды нажать, **Продолжить → Установить** — пароль администратора не
  требуется, предупреждения Gatekeeper не будет (установщик подписан Developer ID
  и заверен Apple).
- Установщик сам кладёт манифест в нужную папку Word и автоматически закрывает Word,
  чтобы изменения подхватились при следующем запуске. Активация надстройки
  (**Главная → Надстройки → sayword.ai**) по-прежнему выполняется вручную, один раз,
  внутри самого Word.
- Требуется macOS 11 (Big Sur) или новее.
- Старый способ с ручным копированием в папку wef по-прежнему работает и описан как
  запасной вариант.
- В этой сборке также обновлён манифест до версии 1.1.1 — исправлена иконка на ленте.
