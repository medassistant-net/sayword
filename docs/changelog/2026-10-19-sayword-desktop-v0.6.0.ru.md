# sayword.ai Desktop — v0.6.0

**2026-10-19**

Командный режим в настольном приложении — и пачка исправлений, которые делают диктовку на
macOS надёжной.

- **Командный режим (раннее превью).** Удерживайте **левый Shift** на Windows или **правый
  Shift** на macOS, скажите, что нужно, — «добавь в правой доле печени кисту двенадцать
  миллиметров» — и отпустите: там, где стоит курсор, появится готовая сформулированная
  находка, а не ваша фраза. Приложение не читает ваш документ, поэтому вставляет только то,
  что вы продиктовали; если просьбу не из чего выполнить, в небольшом окне появится
  уточняющий вопрос. Клавишу можно переназначить или отключить в настройках. Подробнее — в
  статье [«Командный режим: скажите, что нужно, а не что написать»](../notes/2026-10-19-command-mode-overview.md).
- **Текст вставляется один раз — когда вы отпускаете клавишу.** Он больше не появляется в
  документе кусками посреди фразы. Звуковой сигнал начала записи больше не распознаётся как
  слово.
- **Исправлено: истёкший вход проходил молча.** Теперь приложение снова предлагает войти.
- **Исправлено (macOS): нажатие правого Cmd / правого Shift сразу обрывалось** на свежих
  версиях macOS — диктовка так и не начиналась.
- **Исправлено (macOS): окошко диктовки обрезалось и висело посреди экрана** на дисплеях
  Retina. Когда курсор найти не удаётся, оно теперь появляется внизу по центру экрана.
- **Исправлено (Windows): текст больше не может попасть не в то окно.** Если за время
  обработки вы переключились в другое окно, текст окажется в буфере обмена — с
  уведомлением об этом.
- **Настройки сохраняются и применяются сразу, без перезапуска.** Кнопка **Share diagnostic
  logs** в настройках собирает журналы (в них нет ни текста диктовки, ни звука) для
  поддержки.

Сборка для macOS подписана и заверена Apple (универсальный DMG, Intel + Apple Silicon).
Установщики для Windows (x64 и x86) пока без подписи кода — Windows SmartScreen покажет
предупреждение при запуске: выберите **Подробнее → Всё равно выполнить**.
