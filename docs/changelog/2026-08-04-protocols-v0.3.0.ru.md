# Протоколы — v0.3.0

**2026-08-04**

Обновление приложения **«Протоколы»**. Одно изменение, но его просили: **новую партию
протоколов теперь можно догрузить в базу, с которой врач уже работает.**

Раньше такого пути не было вовсе. После первичной обработки приложение всегда открывалось на
интерфейсе просмотра, а повторный запуск обработки отклонялся. Отклонялся не по недосмотру:
полный конвейер заново разбивает протоколы на категории и заново формирует очередь просмотра —
то есть перетасовал бы категории под врачом и пересобрал бы очередь, которую он наполовину
прошёл. Не хватало не обхода этой защиты, а другого режима, который только добавляет. Он и
появился.

## Как это работает

Кнопка **«Добавить протоколы»** внизу списка категорий: выбрать папку, подтвердить число
найденных файлов, дождаться прогресса.

Папка может быть новой или той же самой с досыпанными в неё файлами — приложение узнаёт уже
обработанные протоколы и пропускает их. Повторно они не обрабатываются и не оплачиваются.

Что гарантированно сохраняется:

- **Отметки об одобрении и отклонении** — ни одна стадия их не трогает.
- **Категории уже обработанных протоколов** — новые раскладываются по существующим категориям
  по сходству, а метка проставляется только там, где её не было. Существующий протокол не может
  сменить категорию.
- **Текущая очередь просмотра** — она только пополняется до нормы по каждой категории, ничего
  из отобранного ранее не снимается.

Это проверено не на словах: на копии базы из 18 396 протоколов с 270 одобрениями — все
одобрения уцелели, ни один одобренный протокол не сменил категорию, очередь выросла с 972 до
1304.

Приложение подписано Developer ID и заверено Apple (notarized, Apple Silicon) — открывается
двойным щелчком и устанавливается без подключения к интернету.
