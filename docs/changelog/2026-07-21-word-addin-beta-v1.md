# Word Add-in — Beta v1.0

**2026-07-21**

sayword.ai is now available as a Microsoft Word add-in (beta). It brings real-time
voice dictation of Russian medical/radiology terminology directly into the document at
the cursor position, plus an automated report-verification check once a report is
written.

- Supports Word desktop on Windows and Mac (Microsoft 365 or Office 2021). Office 2016/2019
  and Word Online are not supported for installation via trusted folder.
- Dictation shortcut: `Ctrl+Alt+D` (desktop Word only).
- Report verification flags issues at ERROR / WARNING / INFO levels, with click-to-jump
  navigation to the flagged location.

See the [installation guide](../howtos/2026-07-21-word-addin-installation.md) (Russian)
for setup steps on Windows, Mac, and troubleshooting.
