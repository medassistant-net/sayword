# sayword.ai Desktop — v0.5.1

**2026-07-21**

Релиз с исправлениями для macOS — и первая сборка с установщиками для Windows.

- **Исправлено: диктовка записывала тишину (нулевой сигнал) на macOS.** Подписанная и
  заверенная Apple (notarized) сборка теперь запрашивает разрешение на доступ к микрофону
  (hardened runtime entitlement + TCC) при запуске, поэтому диктовка действительно
  записывает реальный звук, а не тишину — раньше волновая индикация и распознавание не
  работали, при этом никакой ошибки не показывалось.
- **Минимальная версия macOS снижена до 11.0 (Big Sur).** Ранее была зафиксирована
  версия 13.0, хотя ни один используемый API этого не требовал. Теперь приложение
  устанавливается и на более старых Intel Mac (Big Sur / Monterey), а не только на
  Ventura и новее.
- **Добавлены установщики для Windows (x64 и x86).** Пока без подписи кода (ожидает
  EV-сертификат) — Windows SmartScreen покажет предупреждение «неизвестное приложение»
  при запуске: выберите **Подробнее → Всё равно выполнить**, чтобы установить. Подходит
  для внутреннего/пилотного тестирования; для широкого распространения — после подписи.

Сборка для macOS подписана и заверена Apple (универсальный DMG, Intel + Apple Silicon),
проверена через `spctl`/`stapler`.
