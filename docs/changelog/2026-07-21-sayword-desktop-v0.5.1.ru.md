# sayword.ai Desktop — v0.5.1 (macOS)

**2026-07-21**

Релиз для macOS, устраняющий проблему с надёжностью работы десктоп-приложения sayword.ai.

- **Исправлено: диктовка записывала тишину (нулевой сигнал).** Подписанная и заверенная
  Apple (notarized) сборка теперь запрашивает разрешение на доступ к микрофону (hardened
  runtime entitlement + TCC) при запуске, поэтому диктовка действительно записывает
  реальный звук, а не тишину — раньше волновая индикация и распознавание не работали,
  при этом никакой ошибки не показывалось.
- **Минимальная версия macOS снижена до 11.0 (Big Sur).** Ранее была зафиксирована
  версия 13.0, хотя ни один используемый API этого не требовал. Теперь приложение
  устанавливается и на более старых Intel Mac (Big Sur / Monterey), а не только на
  Ventura и новее.
- Windows пока не входит в этот релиз (ожидает EV-сертификат для подписи кода).

Подписанный и заверенный Apple универсальный DMG (Intel + Apple Silicon), проверен
через `spctl`/`stapler`.
